# বাংলা নিউজ পোর্টাল (স্বয়ংক্রিয়, ১০০% ফ্রি, AI দিয়ে লেখা ব্রিফ)

এই প্রজেক্টটা প্রতি ৩০ মিনিট পরপর নিজে থেকেই বাংলা নিউজ সোর্স থেকে খবর টেনে,
প্রতিটা খবরের সংক্ষিপ্ত তথ্যকে AI দিয়ে নিজস্ব ভাষায় নতুন করে লিখে একটা
প্রিমিয়াম-লুকিং পোর্টাল আপডেট করে দেবে — সবটাই ফ্রি টুল দিয়ে
(GitHub Pages হোস্টিং + GitHub Actions অটোমেশন + Google Gemini-এর ফ্রি AI
টায়ার)। **কোনো টাকা খরচ হয় না, কোনো কার্ড লাগে না।**

## এক নজরে কীভাবে কাজ করে
1. `scripts/generate_site.py` কয়েকটা RSS ফিড থেকে খবরের **হেডলাইন, ছোট
   তথ্য, ছবি ও মূল লিংক** নেয়।
2. প্রতিটা খবরের তথ্য Google-এর ফ্রি Gemini API-তে পাঠিয়ে ৪-৫ লাইনের
   নিজস্ব ভাষায় লেখা একটা "ব্রিফ" বানানো হয় (মূল আর্টিকেল কপি না করে,
   তথ্যের ভিত্তিতে নতুন করে লেখা — এটাই কপিরাইট-নিরাপদ পদ্ধতি)।
3. সব মিলিয়ে `docs/index.html` নামে একটা লাল-প্রিমিয়াম-থিমের পোর্টাল পেজ
   তৈরি হয়।
4. `.github/workflows/update-news.yml` প্রতি ৩০ মিনিটে এটা অটোমেটিক চালায়
   ও GitHub-এ কমিট করে দেয়। GitHub Pages `docs/` ফোল্ডারটাকে লাইভ
   ওয়েবসাইট হিসেবে দেখায়।

**AI key ছাড়াও সাইট পুরোপুরি কাজ করবে** — শুধু তখন RSS-এর মূল সারাংশ
দেখাবে, AI-রিরাইট করা ব্রিফ না। নিচের ধাপ ৪ ঐচ্ছিক (optional)।

## সেটআপ (একবারই করতে হবে, প্রায় ১০-১৫ মিনিট)

### ধাপ ১ — GitHub অ্যাকাউন্ট ও রিপোজিটরি
1. [github.com](https://github.com)-এ ফ্রি অ্যাকাউন্ট খোলো (না থাকলে)।
2. একটা নতুন **Public** রিপোজিটরি বানাও, নাম দাও যেমন `bangla-news-site`।

### ধাপ ২ — ফাইলগুলো আপলোড করো
- রিপোর পেজে "Add file" → "Upload files" চাপো।
- এই zip-এর সবগুলো ফাইল ও ফোল্ডার (structure ঠিক রেখে) আপলোড করে দাও।
- "Commit changes" চাপো।

### ধাপ ৩ — GitHub Pages চালু করো
1. রিপোর **Settings → Pages**-এ যাও।
2. "Source" থেকে বেছে নাও: **Deploy from a branch**।
3. Branch: `main`, Folder: **`/docs`** সিলেক্ট করো, তারপর Save।
4. কিছুক্ষণ পর ওখানেই তোমার সাইটের লাইভ লিংক দেখাবে
   (যেমন `https://your-username.github.io/bangla-news-site/`)।

### ধাপ ৪ (ঐচ্ছিক, কিন্তু সুপারিশকৃত) — ফ্রি Gemini API key যোগ করো
এটা করলে খবরের ব্রিফগুলো AI দিয়ে নিজস্ব ভাষায় লেখা হবে। সম্পূর্ণ ফ্রি:

1. [aistudio.google.com](https://aistudio.google.com)-এ গিয়ে Google
   অ্যাকাউন্ট দিয়ে সাইন-ইন করো।
2. **"Get API key" → "Create API key"** চাপো — কোনো কার্ড/বিলিং চাইবে না।
3. তৈরি হওয়া key-টা কপি করো (এটা `AIza...` দিয়ে শুরু হবে)।
4. তোমার GitHub রিপোতে যাও → **Settings → Secrets and variables →
   Actions → New repository secret**।
5. Name: `GEMINI_API_KEY`, Value: (তোমার কপি করা key) — Save করো।

### ধাপ ৫ — অটোমেশন প্রথমবার চালাও
1. রিপোর **Actions** ট্যাবে যাও।
2. "Update Bangla News Site" workflow-টা সিলেক্ট করো।
3. ডানপাশে **"Run workflow"** বাটনে চাপো (প্রথমবার ম্যানুয়ালি চালাতে হবে)।
4. এক-দুই মিনিট পর `docs/index.html` আপডেট হয়ে যাবে এবং সাইটে দেখা যাবে।

এরপর থেকে GitHub নিজে থেকেই প্রতি ৩০ মিনিটে সাইট আপডেট করে দেবে —
তোমাকে আর কিছু করতে হবে না।

## ফ্রি টায়ারের সীমা সম্পর্কে সততার সাথে জানিয়ে রাখি
Gemini-এর ফ্রি টায়ারে প্রতি মিনিটে ও প্রতিদিনে অনুরোধের একটা সীমা আছে
(কার্ড ছাড়া চিরস্থায়ী ফ্রি টায়ার, কিন্তু আনলিমিটেড না)। তাই স্ক্রিপ্ট
প্রতি রানে সর্বোচ্চ ২০টা খবর AI দিয়ে রিরাইট করে ও প্রতিটা কলের মাঝে
বিরতি রাখে, যাতে ফ্রি সীমার মধ্যেই থাকে। বাকি খবরগুলো মূল RSS সারাংশ
দিয়েই দেখানো হয়। Google ভবিষ্যতে এই ফ্রি টায়ারের নিয়ম বদলাতে পারে —
বদলালে `scripts/generate_site.py`-এর `MAX_AI_REWRITES_PER_RUN` ও
`AI_PACE_DELAY_SEC` মান সমন্বয় করে নিলেই হবে।

## কাস্টমাইজ করতে চাইলে
`scripts/generate_site.py` ফাইলের একদম উপরের দিকে এই জিনিসগুলো বদলাতে পারো:
- `SITE_NAME` — সাইটের নাম
- `SITE_TAGLINE` — ট্যাগলাইন
- `FEEDS` — আরো RSS সোর্স যোগ/বাদ দিতে পারো
- `CATEGORY_MAP` — ক্যাটাগরির বাংলা নাম বদলাতে পারো
- আপডেটের সময়সূচি বদলাতে `.github/workflows/update-news.yml`-এর
  `cron: "*/30 * * * *"` লাইনটা বদলাও (যেমন প্রতি ঘণ্টায় করতে `0 * * * *`)

## নিজের কম্পিউটারে টেস্ট করতে চাইলে (ঐচ্ছিক)
```bash
export GEMINI_API_KEY="তোমার-key"   # না দিলেও চলবে, তখন AI-রিরাইট ছাড়া চলবে
python3 scripts/generate_site.py
# docs/index.html ফাইলটা ব্রাউজারে খুলে দেখো
```
কোনো এক্সট্রা লাইব্রেরি ইনস্টল করা লাগবে না — শুধু Python 3 থাকলেই চলবে।

## কপিরাইট সম্পর্কে জরুরি নোট
এই সাইট RSS ফিডের ছোট তথ্যের ভিত্তিতে AI দিয়ে **নতুন করে নিজের ভাষায়
লেখা** ব্রিফ + মূল সংবাদমাধ্যমের লিংক দেখায় (গুগল নিউজের ধাঁচে) — এটাই
নিরাপদ পদ্ধতি। মূল ওয়েবসাইট থেকে পুরো আর্টিকেলের টেক্সট স্ক্র্যাপ করে
এনে "রিরাইট" করাটা ইচ্ছাকৃতভাবে এড়ানো হয়েছে, কারণ (১) সেটা বেশিরভাগ
নিউজ সাইটের Terms of Service ভঙ্গ করে, এবং (২) তথ্য/স্ট্রাকচার হুবহু
থেকে গেলে AI-রিরাইটের পরও কপিরাইট ঝুঁকি থেকে যায়। স্ক্রিপ্টে এটা নিজে
থেকে বদলিও না।
